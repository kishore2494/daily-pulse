# Daily Pulse — Store assets (safe, in-project location)

Regenerable marketing/build assets. Kept HERE (not the Desktop) so they aren't auto-cleaned.

- `feature-graphic.png` — 1024×500 Play feature graphic
- `screenshot-1-log … 5-write.png` — 412×892 phone screenshots (Log, Time, Stats, Calendar, Write)
- `DailyPulse.aab` — signed App Bundle to UPLOAD to Play Console (git-ignored; rebuild from ../../daily-pulse-native)
- `DailyPulse.apk` — signed APK for sideload testing (git-ignored)

Rebuild the .aab/.apk:
  cd ../../daily-pulse-native/android && JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home" ./gradlew bundleRelease assembleRelease
Screenshots/feature graphic are regenerated by the assistant on request.
