# Daylog brand & Play Store set (v256, 2026-11-08)

## The mark
A day rising over the lines of a log: a sunrise half-sun (amber → coral → rose) over three
cream lines on deep ink. It replaced the heartbeat line, which read as a heart-monitor app in
a category full of health apps, and the blue-purple gradients every competitor uses.
- `daylog-logo.svg` — the master (full-bleed square; content stays inside the adaptive-icon safe circle).
- `daylog-icon-512.png`, `-192.png`, `-1024.png` — rendered from it. Copied to `icons/icon-512.png`,
  `icons/icon-192.png`, `icons/icon-maskable-512.png` (web app, landing page, manifest, favicon).
- `daylog-foreground.svg` + `android-res/` — the NATIVE launcher icon: adaptive foreground per density,
  legacy square and round icons, and `values/ic_launcher_background.xml` (#15172F).
  **Not applied yet** — it needs a native build (see below).
- `og-card.png` (repo root) regenerated by `tools/make-og-card.py` with the new icon; accent now #ff8a4c.

## Regenerating
1. Serve the repo (`python3 -m http.server 8471`) and run headless Chrome on CDP 9444.
2. Capture screens: the scratchpad `cap.mjs` flow — clear storage, `eval(tools/seed-store-data.js)`,
   import the six photos through `memImportPrepare` (mode 'one'), set the memory's title/place/people,
   then for each shot `setUiStyle(...)` + navigate + screenshot at 412×892 @2x. Hide the toast with
   `transition:none` before shooting or a fading toast lands in the frame.
3. Render frames: `store-frames.html?f=1..8` at 1080×1920 and `?f=fg` at 1024×500.
